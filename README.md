# Typifo - Smart Online Text Editor

Typifo is a lightweight, smart online text editor that allows users to create and manage documents directly in their web browsers. All documents are stored locally, ensuring privacy and quick access without requiring authentication or cloud storage.

## Features

- **Local Storage Support** - Your documents are saved directly in your browser's local storage, eliminating the need for an account.
- **Voice Input** - Dictate your text using built-in speech recognition.
- **Text Formatting Tools** - Customize font styles, alignment, colors, and more.
- **Table & Image Insertion** - Add tables and images seamlessly into your documents.
- **Export Options** - Save your work as **PDF** or **DOCX**.
- **Auto-save Functionality** - Your progress is saved automatically every few seconds.
